Add birthday pictures for June 19 in this folder.

Use numbered filenames so the frontend can find them automatically:

- `1.webp`
- `2.jpg`
- `3.png`

Supported extensions:

- `.webp`
- `.jpg`
- `.jpeg`
- `.png`
- `.gif`

How it works:

- the app checks this folder only on June 19
- it looks for files `1` through `24`
- each popup rotates to the next available picture and the next birthday message

If you replace or add files here, keep the numbering continuous for predictable rotation.
